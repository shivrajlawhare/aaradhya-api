### Commit messages

Carried over verbatim from the Voyager rules export — fully stack-agnostic.

- Start with an Action Verb: Use verbs like "Add", "Refactor", "Fix", "Implement", "Update", "Delete".
- Be specific: Clearly state the main change or feature in no more than 15 words.
- Provide context: Briefly mention the purpose or impact if needed, keeping the entire message under 120 characters.

### Aaradhya addition: reference the story ID

Per `docs/Aaradhya_Dev_Process_and_Structure.md` §4, append the STORY-ID as metadata after the verb-first message — it does not replace or prefix it:

`Add accommodation totals computation (STORY-018)`

Not `STORY-018: add accommodation totals computation` — the action-verb-first rule above still governs.
